# Otevřené otázky / chybějící data

Tento starter nevychází z kompletního exportu všech historických chatů, pouze z dostupného projektového kontextu.

Proto je potřeba postupně doplnit:

- kompletní finální tabulku jednotlivých misí,
- přesné texty všech Zadání mise,
- přesné podoby Protokolů mise,
- finální mapy perimetru,
- všechny finální grafické soubory,
- kompletní seznam artefaktů u misí, kde v kontextu nebyl vypsán,

Codex musí chybějící data označit, ne odhadovat.
