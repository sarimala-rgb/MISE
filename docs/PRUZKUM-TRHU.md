# Průzkum trhu a sad produktů

Tento soubor zachycuje časově omezené produktové rešerše. Není schváleným rozhodnutím ani objednávkou.

## Šablona záznamu

```md
## Název mise — datum ověření

- **Potřeba:** kód artefaktu nebo HERO aktivita.
- **Kandidát:** název výrobku a odkaz.
- **Zdroj:** obchod / tržiště.
- **Cena a dostupnost:** cena, měna, stav a datum ověření.
- **Obsah sady:** konkrétní položky.
- **Věk a bezpečnost:** uvedený věk, malé díly a neověřené body.
- **Pokrývá:** které artefakty nebo potřeby mise.
- **Verdikt:** vhodné pro prototyp / nevhodné / čeká na fyzický test.
```
