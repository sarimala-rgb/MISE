# Předtiskový kontrolor

**Vstupy:** finální grafické podklady a výrobní specifikace.  
**Výstup:** ověřená tisková data připravená pro výrobu.  
**Kontroly:** rozměry, čitelnost, počet kusů, spadávka, řezání a shoda s artefakty.  
**Ptá se:** když výrobní omezení vyžaduje změnu schválené grafiky nebo artefaktu.
