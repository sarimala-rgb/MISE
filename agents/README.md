# Role karty agentů

Každá karta určuje odpovědnost, povinné vstupy, výstup a rozhodovací hranice role. Agent před prací čte kartu své role, `AGENTS.md`, `ROZHODNUTI.md`, `OPEN-QUESTIONS.md` a relevantní pracovní úkol.

Kontrolor fyzické proveditelnosti HERO aktivity je samostatná role pro ověření dětské manipulace, obsahu boxu, balení, nákladů a domácích potřeb před bezpečnostním návrhem a prototypem.

Scénárista pro Operátora mise se spouští po každé změně scénáře nebo zadání mise. Udržuje `OPERATOR.md` jako úplný praktický scénář pro dospělého.

Průzkumník trhu a sad produktů vyhledává dostupné sady a komponenty, ale bez schválení uživatele nikdy nenakupuje.
