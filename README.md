# M!SE

Pracovní Git repozitář projektu M!SE.

Tento starter je sestaven z rozhodnutí a informací, které jsou v dostupném projektovém kontextu již ustálené. 
Není to kompletní export všech historických chatů. Pokud nějaký detail nebyl v dostupném kontextu explicitně potvrzen, 
je označen jako `TODO` nebo `NEOVĚŘENO` a Codex jej nesmí sám doplňovat.

## Jak s repem pracovat

1. Otevři tento adresář ve VS Code.
2. Spusť Codex nad rootem repozitáře.
3. Codex musí nejdřív přečíst `AGENTS.md`.
4. Globální pravidla jsou v `docs/PRAVIDLA-MISI.md`.
5. Každá mise má vlastní `MISE.md` a `ARTEFAKTY.md`.
6. Pokud v chatu vznikne nové rozhodnutí, zapiš jej do příslušného souboru — chat není zdroj pravdy.

## Zdroj pravdy

Priorita při konfliktu:

1. explicitně schválený obsah konkrétní mise,
2. `docs/PRAVIDLA-MISI.md`,
3. `docs/ROZHODNUTI.md`,
4. ostatní poznámky.

Codex nesmí nahrazovat chybějící obsah odhadem.

## Aktuálně rozpracované specializace

1. Paleontolog
2. Strážce draků
3. Lovec pokladu
4. Konstruktér
5. Tajný agent

Adresáře v `missions/` používají toto pořadí a číslování.
