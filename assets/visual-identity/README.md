# Vizuální identita M!SE

Známé schválené / ustálené body:

- Logo musí přesně vycházet ze schváleného vizuálního vzoru.
- Razítko má působit jako sofistikovaná pečeť.
- U dokumentu Zadání mise:
  - odstranit sub-popisky uvnitř boxů,
  - používat správné písmo dle identity,
  - boxy a vnější rám mají lícovat,
  - preferovat hranatější obrysy.

## Chybějící soubory
Původní referenční obrázky a vygenerované grafiky nejsou automaticky přeneseny, protože nejsou v aktivním filesystemu této konverzace.
Vlož je sem jako zdrojové/reference soubory, jakmile budou dostupné.
